# dsh-tasks 月度 lint 定时项（提示词模板）

在 dsh-tasks 里新建定时事项（建议每月一次，如 `0 9 1 * *`），提示词如下（按实际路径调整知识库根目录）：

---

对知识库（根目录 `$DSH_KB_ROOT`，默认 `~/.dsh/kb`）做月度 lint，按 dsh-kb 技能的约定执行：

1. 读 `schema.md` 和 `index.md`
2. 找死链：所有 wiki 页面里的 `[[...]]`，目标页面不存在的列出来
3. 找孤儿页：wiki/ 下没有被 index.md 或任何其他页面链接到的页面
4. 找陈旧条目：frontmatter `updated` 超过 90 天的页面
5. 把结果写成 `wiki/meta/lint-YYYY-MM.md`（分三节：死链 / 孤儿页 / 陈旧条目，每项给出建议处理方式：改链接 / 挂 index / 提请复审）
6. `index.md` 不动，`log.md` 追加一行记录本次 lint
7. 最后输出一段简短总结：各节多少项、最需要人工处理的是哪几条

只做检查与清单，不要自行删除或大改任何页面。

---

## 建议配置

- 标题：`KB 月度 lint`
- cron：`0 9 1 * *`（每月 1 号 09:00）
- 工作区：默认即可（提示词里用的是绝对路径）
